\section*{ADNU Manuscript Revision Plan}

This revision plan defines the source-level changes used to align the
manuscript with the Ateneo de Naga University ECE/CpE manuscript format while
preserving IEEE-style numbered citations.

\subsection*{Formatting and Pagination}
\begin{enumerate}
  \item Set global margins to 1.0in top, 1.0in bottom, 1.0in right, and
  1.25in left through the manuscript preamble.
  \item Use Times New Roman as the manuscript font, 12pt double-spaced body
  text, justified paragraphs, and 1.50cm first-line indentation.
  \item Keep major-title pages on bottom-centered page numbers and ordinary
  pages on upper-right page numbers through the existing page-style controls.
  \item Rebuild the title page with the required font sizes and single-space
  counts for the title, authors, submission statement, university line, and
  date.
\end{enumerate}

\subsection*{Structure and Headings}
\begin{enumerate}
  \item Keep Chapter 4 as \textbf{RESULTS AND DISCUSSION} and Chapter 5 as
  \textbf{CONCLUSION AND RECOMMENDATION}.
  \item Reduce Chapter 3's second-level heading load by grouping method content
  under system model, firmware flow, hardware implementation, TinyML workflow,
  calibration, socket-heating model, waveform features, protection logic, and
  evaluation procedures.
  \item Remove the redundant major section previously titled ``System Inputs,
  Processing, and Outputs'' by folding the useful material into the system
  model as a lower-level summary.
  \item Limit technical subdivisions to fourth-level headings.
\end{enumerate}

\subsection*{Tables, Captions, and Figures}
\begin{enumerate}
  \item Use global table rules of 1.5pt for top, header, and bottom rules, with
  1.0pt inner rules where needed.
  \item Format table captions so only the table number label is bold and the
  title is regular.
  \item Rework Table 2.1 and Table 2.2 as real LaTeX tables with concise
  headers, bold header rows, horizontal rules only, and no double bottom
  lines.
  \item Replace low-resolution block diagrams and flowcharts with TikZ diagrams
  that use consistent fonts, line weights, arrow styles, and spacing.
  \item Regenerate calibration, socket-heating, and model-performance graphs
  with LaTeX-native plotting where source values are available.
  \item Place the full schematic as a dedicated landscape figure and scale the
  source PDF so its labels and circuit sections remain readable.
\end{enumerate}

\subsection*{Feature-Set Contract}
\begin{enumerate}
  \item Verify feature names and model inputs from the firmware, trainer, PWA,
  and exported model headers before revising the manuscript claims.
  \item State the verified behavior: the firmware computes and logs 20
  waveform-related candidate features.
  \item State the deployed arc-model behavior: the Random Forest arc model uses
  six waveform features plus six context one-hot fields and one context
  confidence value, for 13 total inputs.
  \item State the PWA behavior: the dashboard displays 14 waveform-feature
  cards while additional computed features remain in logs or internal logic.
  \item Add a contract table that distinguishes logged features, deployed
  arc-model inputs, PWA cards, and physical interpretations.
\end{enumerate}

\subsection*{Socket-Heating and Protection Claims}
\begin{enumerate}
  \item Use ``Device Measurement'' for the prototype thermistor channel,
  ``Infrared Thermometer'' for the reference terminal/contact reading, and
  ``Estimated Socket Temperature'' for the compensated estimate.
  \item Separate expected normal temperature from estimated socket temperature
  in the derivation.
  \item Present the least-squares gain and regression framework without
  inventing missing constants or source data.
  \item Treat voltage monitoring as voltage supervision unless experimental
  validation data support a stronger protection claim.
\end{enumerate}

\subsection*{Appendices and References}
\begin{enumerate}
  \item Insert an all-caps, centered, unnumbered \textbf{APPENDICES} divider
  with a table-of-contents entry.
  \item Keep appendices lettered continuously from Appendix A through
  Appendix I and remove duplicate immediate subtitles.
  \item Reformat Appendix G letters with formal letter spacing and signature
  blocks instead of signatory tables.
  \item Rebuild Appendix H as an editable landscape Gantt chart.
  \item Reduce Appendix I to a plain professional cost-breakdown table.
  \item Preserve IEEE bracketed citations and keep the bibliography in a
  fixed-width numbered format.
\end{enumerate}

\subsection*{Verification}
\begin{enumerate}
  \item Build the main PDF and all section, chapter, and appendix PDFs using
  the project build script.
  \item Inspect rendered pages for the title page, Chapter 3 figures and
  tables, the full schematic, Chapter 4 graphs, Appendix G letters, Appendix H
  Gantt chart, and Appendix I cost table.
  \item Report unresolved source-data limits explicitly instead of inventing
  experimental constants, missing measurements, or citations.
\end{enumerate}
